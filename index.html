    Winner Spotlights

    Grand Prize · Build with DataHub

    Project Blackbox

    Creator: Alex Velazquez

    An autonomous data incident response agent. It takes plain-English anomaly reports, traces them back to their root cause using DataHub lineage, automatically repairs the broken code, and opens a pull request that includes machine-verified proof of the fix.

    View Project on Devpost →
    Overall Winner · ARM Create

    Literally the Smallest 0.5B Param Functional LLM Ever Built

    Creators: Bitan Nath & Swati Ram

    A 0.5B parameter LLM running at ~3 tokens/sec on an Apple Watch using only 64 MB of peak RAM. Built in Zig with ARM NEON SIMD instructions and memory mapping (mmap) — the first publicly working multi-turn conversational LLM on wearable hardware, demoed with a mood-uplifting agent.
